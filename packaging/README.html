鳥類監控系統｜可攜版

適用 Windows 10/11 64 位元（x64）。內附 Python 與 Pillow，不必安裝 Anaconda。需要 Chrome 或 Edge，以及開發板 USB 序列埠驅動程式（若裝置管理員未顯示 COM 埠，需安裝板卡對應驅動）。

本次更新：0.15.2

偵測預設改為 20%，分群合併門檻仍為 76%。重量增加單筆跳值過濾及大幅變動確認；變動確認中不顯示新重量，舊穩定值會標成保留值。新值持續穩定 5 秒後才採用。

校正會在最多 30 秒內持續找穩定樣本，不會一晃就失敗。20/20 筆仍可能正在等穩定，請等「板端已完成」。校正只檢查重量資料，不再被畫面中的鳥、鳥類圖片或視覺失聯擋住。使用者確認秤台上無鳥、無碰觸即可；重量不穩仍會等待或逾時。

需要重新燒錄新版韌體才能啟用以上板端功能。只更新此資料夾與重整網頁不夠。firmware-binaries 內已包含新版韌體；使用原專案 Build.ps1 -Upload 與已安裝 SDK 燒錄。更新保留此資料夾原有照片、到訪資料與 settings.json。

啟動

  1. 把整個資料夾複製到可寫入的位置；不要只複製啟動檔。避免同時從兩台電腦操作同一份共享資料。
  2. 接上 AMB82 序列埠 USB 與 OTG 影像 USB。已燒錄的板子不必再燒錄。
  3. 雙擊 Start.cmd，保留服務視窗；瀏覽器會開啟 http://localhost:8080。
  4. 在即時監控啟動 USB 攝影機並允許攝影機權限，選擇 AMB82 UVC。
  5. 結束時先停止攝影機，再執行 Stop.cmd，等服務視窗退出後才拔線或複製資料夾。

沒有開發板時會以離線模式瀏覽歷史紀錄，不會生成模擬偵測。若有多個 COM 埠，修改 settings.json 的 serial_port，例如 "COM4"。web_port 預設 8080，資料服務使用其加二埠號；若被原版佔用，請先停止原版。

資料與搬移

data/ 包含到訪資料庫、分群修正與照片；records/ 保存板端事件。搬移與備份請先停止服務，再複製整份資料夾。這是一份獨立快照；原專案與可攜版之後的新增、刪除、分群不會互相同步。刪除照片／到訪會影響此資料夾的紀錄，請定期備份。

網址 localhost 指的是目前這台電腦。其他電腦或手機不能只輸入此網址取得這台電腦的 USB 畫面；此版是搬到新 Windows 電腦執行，不是雲端網站。

雙重量感測器

每組秤新增「即時感測數值」：原始 ADC、過濾值、與上一筆的差值及最近 60 筆走勢，校正前及校正中也能查看。ADC 不是公克；曲線縱軸自動縮放，請同時看波動範圍。斷線會清空即時值及曲線。本次顯示更新只需重新整理網頁，解除校正視覺限制仍需燒錄 0.15.1 韌體。

飼料、水各使用一組 HX711：飼料 DT=D1、SCK=D2；水 DT=D3、SCK=D4。請依硬體接線與原專案說明確認電源。只監測重量，不控制馬達或水泵。

  1. 保持秤台穩定、沒有鳥站上去（不用移開鏡頭前的鳥類圖片）；移除內容物，保留正常使用的容器。
  2. 先對該秤執行空載歸零。
  3. 放上已知重量（例如實際量好的 100 公克），輸入相同公克數，執行校正並等成功回覆。
  4. 取下砝碼，確認接近零，再放回確認接近已知重量；水、飼料兩組分別做。

校正不是直接將任何讀值改成想要的重量。鳥停留造成晃動時先等鳥離開、重量穩定，再重新量測；裝有內容物時不要隨意空載歸零。開發板重開機後請確認校正狀態，需要時重新校正。

原始碼與韌體

archive、dashboard、Start-Demo.ps1 為執行程式；firmware 與 firmware-binaries 保留板端原始碼及韌體。根目錄保存開發腳本與 tests 測試；development 保存版本歷史。日常執行不需要 Arduino SDK；重編譯或重新燒錄需另依原專案安裝工具，二進位檔不是一鍵燒錄器。

runtime-sources.json 記錄執行環境來源與校驗碼；package-manifest.json 記錄此份打包版本。歷史報告與影片不包含於執行包。
